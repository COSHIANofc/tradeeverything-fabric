# TradeEverything

TradeEverything は Minecraft 26.2 向けの Fabric MOD です。新規生成されるバニラの沼地の小屋では、Witch を TradeEverything の商人に置き換えます。小屋と Cat はそのままで、既に生成された小屋は変更しません。

## 導入

クライアントとサーバーの両方に、Fabric Loader 0.19.3 以上、Fabric API 0.157.0+26.2 以上の互換版、TradeEverything 0.8.b-dev を導入してください。Minecraft 26.2 と Java 25 が必要です。Fabric API と `tradeeverything-0.8.b-dev.jar` を両方の `mods` ディレクトリへ入れます。

## 取引

商人は検索可能な1つのカタログで Buy と Sell を提供します。一度に表示される結果は7件で、マウスホイールでスクロールできます。検索はアイテム名とレジストリ ID を対象にし、前後の空白と大文字・小文字を区別せず、部分一致で探せます。

- 数量ボタンで取引数を選べます。修飾キーを使った高速な増減も利用できます。
- Buy の支払いにはエメラルドとエメラルドブロックを使えます。エメラルドブロック1個はエメラルド9個分で、先にエメラルドを使い、つり銭はエメラルドで返します。
- エンチャント本はバニラエンチャントごとに1つの項目です。修繕のようにレベルが1つだけのものを含め、選べるレベルから購入できます。
- ポーションは効果ごとにまとめられています。利用可能な種類を選び、通常／スプラッシュ／残留ポーションを選択できます。

取引が完了する前に、価格、選択内容、支払い、インベントリの空きがサーバーで確認されます。

## 設定

設定ファイルは `config/config` です。Buy と Sell はアイテムごとに独立して設定できます。

```json
{
  "items": {
    "minecraft:diamond": {
      "enabled": true,
      "buy": {
        "emeralds": 24,
        "output": 1
      },
      "sell": {
        "items": 4,
        "emeralds": 3
      }
    },
    "examplemod:ruby": {
      "enabled": true,
      "buy": {
        "emeralds": 8,
        "output": 1
      },
      "sell": {
        "items": 1,
        "emeralds": 4
      }
    }
  }
}
```

`buy.emeralds` はエメラルド価格、`buy.output` は1回の購入で受け取る数です。`sell.items` と `sell.emeralds` はまとめ売りの比率です。`items: 4`、`emeralds: 3` なら、**4個売るごとにエメラルド3個**を受け取ります。そのため4個・8個は有効で、5個は無効です。`sell` を指定しない場合は、通常のSell価格が使われます。

旧形式の設定も使えます。

```json
{
  "enabled": true,
  "emeralds": 24,
  "output": 1
}
```

この形式の `emeralds` と `output` は Buy の設定だけを意味します。旧形式と新しい `buy` を同時に書いた場合は、新しい `buy` が優先されます。既存の設定ファイルを読み込んでも、自動的に書き換えません。

対象のバニラアイテムは自動的に利用できます。MOD アイテムは有効な明示設定が必要で、MOD 自体も導入されていなければなりません。存在しない ID は安全にスキップします。設定で生成する MOD アイテムは通常のアイテム状態であり、独自の特殊な状態は設定から作成できません。

## 進捗

商人との取引が成功すると進捗が付与されます。全アイテム進捗では、対象のバニラアイテムは個別に数え、すべてのエンチャント本は1カテゴリ、すべてのポーションの種類と容器は1カテゴリとして数えます。MOD アイテムは必要数に影響しません。現在の必要数は1411項目です。中身入りシュルカーボックスを売った場合は中身を数え、手元に残る空の箱は数えません。

## コマンド

権限レベル2が必要です。

```text
/tre summon [<x> <y> <z>]
/tre verify
/tre reload
```

`/tre summon` は管理・確認用に商人を作成します。既存の沼地の小屋は変更しません。
